# Agentic AI 開発実践 - Strands Agents 版 演習ガイド

本サイトは、「Agentic AI 開発実践 - Strands Agents 版」研修コースの受講者向け演習ガイドです。

社内ITヘルプデスクエージェントを、演習①から演習⑥まで段階的に構築していきます。各演習のガイドには、ベースコードファイルのどこにどのコードを追加すればよいかが、`TODO`番号付きで示されています。

[演習ガイドを開く →](/guide/)

## 演習の進め方

1. 左のサイドバー、または上記リンクから対象の演習ガイドを開きます。
2. ガイドで指示されたベースコードファイル（`code/`配下）を、自分の作業用ディレクトリにコピーします。
3. ガイドの手順に沿って、`TODO`番号の場所にコードを追加・書き換えます。
4. 動作確認チェックリストに沿って、エージェントが期待どおりに動くことを確認します。
