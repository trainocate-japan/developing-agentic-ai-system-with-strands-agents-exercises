# 演習ガイド 一覧

一貫シナリオ「社内ITヘルプデスクエージェント」を、6つの演習で段階的に構築します。各演習のベースコードには、前の演習の完成形があらかじめ組み込まれています。

| 演習 | 内容 |
|---|---|
| [演習1](/guide/module3/exercise1.md) | 最小構成エージェント |
| [演習2](/guide/module4/exercise2.md) | 複数ツールを持つ単一エージェント |
| [演習3](/guide/module5/exercise3.md) | Graphによる一次切り分け |
| [演習4](/guide/module6/exercise4.md) | 永続化・Hooks・HITL |
| [演習5](/guide/module7/exercise5.md) | MCPサーバーへの接続 |
| [演習6](/guide/module8/exercise6.md) | Guardrails設定と評価結果の確認 |

各演習のベースコードには、使用するモデルのIDが入っていません。演習を始める前に、[共通準備: モデルIDの書き換え](/guide/model-id.md)を確認してください。
